{{placeholder}} values come from the SOAP variables below.
One name=value per line, for example sit_osb=https://osb-sit.example.com. Blank lines and # comments are ignored.
Placeholders: {{fromMailFromConfiguration}}, {{toMailDynamic}}, {{subjectDynamic}}, {{htmlBodyDynamic}} (inserted as HTML, inside the CDATA), {{username}} / {{password}} (the SOAP credentials above) and any variable from the list. Values placed in XML are escaped automatically. Clearing the box restores the built-in template.
Defaults come from app.mail.* in application.yml; clearing a field restores the configured default.
